# Pilot CCTV sample clips

Drop NVR exports here for offline threshold calibration.

See [docs/pilot-recordings.md](../docs/pilot-recordings.md) for required scenarios and naming.

```
cam-01/   still.jpg + scenario mp4s
cam-02/   still.jpg + scenario mp4s
calibration/notes.md
```

Video files are gitignored. Keep this folder on the factory inference host or a secure local drive.
